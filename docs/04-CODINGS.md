## Method

Two independent coders per party (never shown each other’s work), each producing one code per statement on the contract scale (see `docs/SCHEMA.md`): `-2` strongly disagree · `-1` disagree · `0` explicitly neutral · `+1` agree · `+2` strongly agree · `null` = the party has no stated position (never guessed).

Every non-null row ships a **verbatim quote**. Each quote is checked mechanically as an exact substring of the stored source file; the cited source must also be a trusted record (stored bytes hash-matching its `sources.json` entry). A quote that does not verify is never edited: if the same verbatim text exists in another trusted source of the same party, the citation is re-pointed to that record (logged in `data/codings/_citation_audit.json`); otherwise the row is quarantined (`_quarantined.json`) and excluded here.
