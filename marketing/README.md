# marketing/ — owned by the marketing director agent

Campaign materials for BC Vote Match: visuals (generated on the vast.ai instance), copy, influencer and media kits.

## Boundary
- This directory is the marketing director's. Other agents: do not edit it.
- The marketing agent may READ `data/`, `docs/`, and the built site. It must not edit `data/`, `src/`, `agents/`, `scripts/`, or `docs/`.
- If a code or content change is needed, raise it with the marketing owner rather than editing.

## Neutrality boundary (important)
The product earns its credibility by being method-neutral. Outreach framing is where any viewpoint lives, and it must never assert that a party is wrong or tell anyone how to vote. Materials should invite people to compare their own views with the parties. Anything that reads as partisan must be flagged to Martin before it is used.

## Versioning
Same rules as `docs/CONTRIBUTING.md`. Commit scope is `marketing`, signed with `Agent: <id>`. For generated images, record the source prompt, model and seed alongside the asset so it is reproducible.
